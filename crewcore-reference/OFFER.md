# Corresponding source offer

The APK's embedded `assets/source/crewcore-corresponding-source.zip` is described by its own offer document as containing pinned upstream sources, the one modified BepInEx adapter, build scripts and license texts for the copyleft components.

The offer explicitly states that CrewCore's own loader source is proprietary and is not included. Therefore the embedded source archive does not provide the full source project needed to rebuild or directly edit the CrewCore Android app.

This note records what was found in the uploaded APK; it does not replace the original archive or its license texts.
